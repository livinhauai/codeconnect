# 💻 CodeConnect

CodeConnect é uma interface web para cadastro de projetos de tecnologia, permitindo a seleção de tags temáticas, upload de imagem e descrição detalhada do projeto. Desenvolvido com foco em praticar **HTML**, **CSS** e **JavaScript** puro, o projeto simula a publicação de um portfólio de forma interativa e responsiva.

## 🚀 Funcionalidades

- Upload de imagem com visualização imediata;
- Preenchimento de nome e descrição do projeto;
- Adição de tags com verificação de disponibilidade;
- Botões para **publicar** (simulado) ou **descartar** o projeto;
- Interface moderna e responsiva, com design escuro e destaque de cores;
- Estilo consistente utilizando variáveis CSS (`:root`).

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (com variáveis e flexbox)
- JavaScript (DOM, eventos, Promises, FileReader)

- O botão **Publicar Projeto** simula uma requisição assíncrona e pode dar certo ou errado aleatoriamente (50%).

## 🧠 Aprendizados

Esse projeto foca na manipulação de DOM, leitura de arquivos com `FileReader`, promessas assíncronas e feedback visual ao usuário. Foi idealizado como uma prática criativa para desenvolvimento front-end sem frameworks.
